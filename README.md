# My Days

**My Days** is a daily calendar app for Android and iOS/iPadOS that turns any date into a rich snapshot of history, astronomy and culture. Its daily content is researched with the help of Google's Gemini AI and prepared in advance.

For each day it shows:
- Sunrise, sunset and moon phase for your own location
- Saints of the day and international observances
- Famous birthdays, historical events and a quote of the day
- Content in English, Spanish, Portuguese or Catalan

This repository holds the app's public side: the pre-generated daily content (`content/`, served through jsDelivr), the scripts and workflows that generate and check it, and the public web pages (`docs/`, served through GitHub Pages).
