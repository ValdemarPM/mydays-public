Política de Privacidad

Última actualización: 29 de septiembre de 2026

También disponible en: English · Português · Català

Esta Política de Privacidad describe cómo My Days ("la app") gestiona la información cuando la utilizas. My Days es una app de calendario y eventos históricos que usa la IA Gemini de Google para generar contenido sobre fechas concretas.

1. Información que Procesamos

Cuando tocas una fecha, la app envía lo siguiente a la API de Google Gemini:

  • La fecha del calendario seleccionada
  • El idioma configurado en tu dispositivo

Para mostrar las horas de salida/puesta de sol, las fases lunares y las estaciones de tu propia ubicación, la app también determina una ubicación aproximada de tu dispositivo — consulta la Sección 4 para más detalles. La app no recopila, almacena ni transmite tu nombre, correo electrónico, identificadores del dispositivo ni datos de cuenta.

2. Cómo Se Usan los Datos

La fecha y el idioma se envían únicamente para generar información histórica y astronómica sobre esa fecha mediante IA. La respuesta se muestra en la app y no se almacena ni se registra.

3. Servicios de Terceros

La app utiliza la API de Google Gemini para generar contenido. Los datos enviados a esta API están sujetos a la Política de Privacidad de Google. También utiliza ipwho.is, ipinfo.io y la API de Geocodificación de Open-Meteo para la detección y búsqueda de ubicación — consulta la Sección 4 para más detalles. La app no utiliza ningún servicio de terceros de analítica, publicidad o seguimiento.

4. Ubicación

My Days utiliza una ubicación aproximada — obtenida a partir de la dirección IP de tu dispositivo mediante el servicio de terceros ipwho.is (o ipinfo.io como alternativa si no está disponible) — para calcular con precisión las horas de salida/puesta de sol, las fases lunares y las estaciones de donde te encuentras, en lugar de usar una ubicación fija predeterminada. Esta consulta se realiza automáticamente una vez (al primer inicio, o cada vez que pulsas "Usar mi ubicación" en Ajustes) y no está vinculada a ningún otro dato que procese la app. La ubicación resuelta (coordenadas, zona horaria y una etiqueta legible como "Ciudad · Región · País") se guarda únicamente en tu dispositivo — consulta la Sección 7.

También puedes buscar una ubicación por nombre en Ajustes para corregir la ubicación detectada o consultar los datos de otra región. Estas búsquedas se envían como texto simple a la API de Geocodificación de Open-Meteo, un servicio de terceros, y no están vinculadas a tu dirección IP ni a ningún otro dato que procese la app.

My Days nunca accede al GPS ni a los servicios de ubicación precisa de tu dispositivo — solo a la ubicación aproximada basada en IP descrita anteriormente, o a una ubicación que busques explícitamente.

5. Almacenamiento de Datos

My Days no dispone de servidores que almacenen datos de usuario. No se requiere ninguna cuenta y no se conserva ningún dato personal después de cerrar la app.

6. Notificaciones Locales

My Days puede enviarte opcionalmente una notificación diaria local con un dato destacado sobre la fecha actual. Esta notificación se programa íntegramente en tu dispositivo mediante el sistema de notificaciones de Android: no se envían datos a nosotros ni a terceros para habilitarla, y no interviene ningún servidor de notificaciones push. Puedes activar, desactivar o reprogramar esta notificación en cualquier momento desde los Ajustes de la app, y puedes revocar el permiso de notificaciones desde los ajustes del sistema de tu dispositivo.

7. Preferencias Almacenadas en tu Dispositivo

Tus preferencias de notificación (si están activadas, la hora programada y el tipo de contenido que quieres ver) y tu ajuste de ubicación (Sección 4) se guardan únicamente en tu dispositivo. Estos datos nunca se transmiten a nosotros, y se eliminan automáticamente si desinstalas la app.

8. Privacidad de Menores

La app no está dirigida a menores de 13 años. No recopilamos conscientemente ninguna información de menores.

9. Cambios en Esta Política

Si esta política cambia, la versión actualizada se publicará en esta misma URL con una fecha de "última actualización" revisada.
